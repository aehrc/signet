Signet {{ .Chart.AppVersion }} is installed as {{ include "signet.fullname" . }}.

Public origin: {{ .Values.publicUrl }}

Endpoint issuers are derived from that origin:

    {{ .Values.publicUrl }}/t/{tenant}/e/{endpoint}

To put Signet in front of a FHIR server, point that server's authorization
issuer at the endpoint. For Pathling that is three settings:

    PATHLING_AUTH_ENABLED:  "true"
    PATHLING_AUTH_ISSUER:   "{{ .Values.publicUrl }}/t/{tenant}/e/{endpoint}"
    PATHLING_AUTH_AUDIENCE: "<your FHIR base URL>"

{{ if not .Values.masterKey.existingSecret -}}
WARNING: no existing secret was supplied for the signing-key envelope key, so
the chart generated one into {{ include "signet.fullname" . }}-master-key. It is
annotated `helm.sh/resource-policy: keep` so upgrades preserve it. Back it up -
if it is lost, every stored endpoint signing key becomes undecryptable and every
client must be re-registered. For production, manage it externally and set
`masterKey.existingSecret`.
